Hướng dẫn kiểm thử Giai đoạn 1 & 2

CVAT Dataset & Ground Truth + YOLO Evaluation

Lưu ý: model yolov8x.pt đóng gói trong image được pretrained trên COCO (80 class), không phải BDD100K. Có thể dùng model này để kiểm tra pipeline hoạt động, nhưng metrics chỉ có ý nghĩa chính thức khi dùng model đã fine-tune đúng 10 class BDD100K.
Nội dung
  1. Khởi động hệ thống
  2. Tạo Task BDD100K
  3. Kiểm thử Giai đoạn 1
  4. Gán Ground Truth
  5. Kiểm thử Giai đoạn 2
  6. Kiểm tra kết quả và xử lý lỗi

1. Khởi động hệ thống

Yêu cầu máy đã cài Docker Desktop và Docker Engine đang chạy.

Máy mới clone project lần đầu

git clone <repository-url>
cd cvat-UI
docker compose up -d

Máy đã từng chạy phiên bản cũ

git pull
docker compose pull
docker compose up -d --force-recreate

Kiểm tra container:

docker compose ps

Các container quan trọng như cvat_server, cvat_ui và cvat_db phải có trạng thái Up.

Kiểm tra migration:

docker exec cvat_server python manage.py showmigrations yolo_evaluation

Kết quả mong đợi:

yolo_evaluation
 [X] 0001_initial

Kiểm tra model đã có trong custom image:

docker exec cvat_server ls -lh /opt/cvat/evaluation-data/models/yolov8x.pt

  2. Đặt tên Task, ví dụ BDD100K Evaluation Test.
  3. Upload ảnh từ thư mục bdd100k_samples.
  4. Trong phần Labels, chọn chế độ Raw và paste JSON bên dưới.

3. Kiểm thử Giai đoạn 1

Mở trang chi tiết Task, ví dụ:

http://localhost:8080/tasks/1

Không mở trang /tasks/1/jobs/1, vì đó là màn hình annotation.

  1. Nhấn Dataset & Evaluation.
  2. Chọn Random uniform.
  3. Nhập Number of frames: 5.
  4. Nhập Random seed: 42.
  5. Nhập metadata điều kiện.
{
  "dataset": "BDD100K",
  "split": "test",
  "weather": "mixed",
  "scene": "city street",
  "time": "daytime"
}

Nhấn Create Ground Truth dataset.

Thành công khi trang hiển thị GT Job #... — 5 frames và Task xuất hiện Job có nhãn Ground truth.

Ý nghĩa Random seed

Cùng Task, số frame và seed sẽ tạo cùng tập frame. Đổi seed thường tạo tập frame khác.

Seed 42  → [1, 4, 8]
Seed 100 → [0, 5, 7]
Seed 42  → [1, 4, 8]

4. Gán Ground Truth

  1. Quay lại trang Task.
  2. Mở Job có nhãn Ground truth.
  3. Vẽ bounding box và chọn đúng label cho tất cả đối tượng cần đánh giá.
  4. Kiểm tra đủ tất cả frame.
  5. Nhấn Save.
Ground Truth phải được kiểm tra thủ công và chính xác. Annotation sai sẽ làm mAP, Precision, Recall và confusion matrix sai theo.

5. Kiểm thử Giai đoạn 2

Mở lại trang Dataset & Evaluation và nhập:

TrườngGiá trị kiểm thửÝ nghĩa
Model path /opt/cvat/evaluation-data/models/yolov8x.pt Model YOLO được đánh giá
Confidence0.25Loại prediction có độ tin cậy thấp hơn 25%
IoU0.5Ngưỡng chồng lấp dùng trong validation/NMS

Nhấn Run evaluation on Ground Truth. Backend sẽ tự động:

  1. Export Ground Truth Job sang định dạng Ultralytics YOLO Detection.
  2. Chạy validation và inference trên đúng các frame GT.
  3. Tính mAP50, mAP50–95, Precision, Recall và confusion matrix.
  4. Lưu bbox, class ID, confidence và tên ảnh của prediction.
  5. Xóa dataset tạm sau khi hoàn tất.

YOLOv8x chạy bằng CPU có thể mất vài phút. Không nhấn chạy nhiều lần trong khi request trước vẫn đang xử lý.

6. Kiểm tra kết quả

Run thành công cần có:

  • Status: completed
  • mAP50 là giá trị số
  • Precision là giá trị số
  • Recall là giá trị số

Kiểm tra metrics trực tiếp:

docker exec cvat_server python manage.py shell -c "from cvat.apps.yolo_evaluation.models import EvaluationRun; r=EvaluationRun.objects.latest('id'); print(r.status); print(r.metrics); print(r.error)"

Kiểm tra prediction:

docker exec cvat_server python manage.py shell -c "from cvat.apps.yolo_evaluation.models import EvaluationRun; r=EvaluationRun.objects.latest('id'); print('Images:', len(r.predictions)); print(r.predictions[:1])"

7. Xử lý lỗi thường gặp

LỗiCách kiểm tra
No installed app with label yolo_evaluation Chạy docker compose pull rồi recreate container.
Không thấy nút Dataset & Evaluation Mở trang /tasks/{id}, hard refresh bằng Ctrl+Shift+R.
Model path does not exist Kiểm tra model bằng lệnh ls ở bước 1.
Run có status failed Xem trường Error trên dashboard và log backend. 
docker logs cvat_server --tail 300
Không sử dụng metrics từ yolov8x.pt COCO làm kết luận chính thức cho BDD100K. Để đánh giá đúng, thay model path bằng file best.pt đã fine-tune trên cùng 10 class và cùng thứ tự class của Task.
